# Security Policy

## Reporting a vulnerability

Do not publish credentials, exploit details, private endpoints or sensitive configuration in a public issue.

When private vulnerability reporting or GitHub Security Advisories are enabled for this repository, use that private reporting channel.

## Repository rules

Never commit:

- API keys
- bearer tokens
- passwords
- cookies
- private certificates or keys
- production `.env` files
- internal endpoint inventories
- organization-specific datasets
- private research material

## Scope

Security claims are bounded to the source and tests actually published here.
